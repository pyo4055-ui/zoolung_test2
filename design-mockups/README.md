# 주렁주렁 동탄 단체예약 / 현장스케줄 UI 디자인 기준

2026-08-22 기준 디자인 시안 방향을 보관합니다.

## 확정한 방향

- 기존 단체예약 / 현장스케줄의 기능 구조와 기능 위치는 최대한 유지
- 기능 로직은 건드리지 않고 최종 단계에서 UI/CSS 위주로 입히기
- 기존 화면의 엑셀/업무표 느낌을 줄이고 주렁주렁 공식 브랜드 분위기로 변경
- 이모지/이모티콘은 사용하지 않음
- 사용자가 제공한 주렁주렁 로고를 헤더의 브랜드 기준으로 사용

## 단체예약 디자인

현재 프로젝트의 예약 정보 입력 흐름과 우측 요약 영역을 유지하되, 흰색 카드 + 크림 배경 + 버건디 메인 버튼 + 오렌지 강조 컬러로 정리한다.

시안 파일명: `zoolung_group_reservation_brand_mockup.html`

## 현장스케줄 디자인

현재 현장스케줄의 날짜 선택, 운영/취소/예약 유료/현장 유료/현장 인솔 요약, 4F/5F/식사/놀이터/기타 범례, 단체별 카드, 타임라인, 메모, 인상착의, 결제완료/컬러북 제공 구조는 유지한다.

기존 컨텐츠 구분색은 유지하되 전체 바탕과 헤더/버튼은 주렁주렁 브랜드 색으로 정돈한다.

시안 파일명: `zoolung_field_schedule_brand_mockup.html`

## 최종 적용 원칙

디자인이 최종 확정되기 전까지 기존 운영 코드는 수정하지 않는다. 최종 적용 시 기존 Firebase/Firestore 연동, 예약 확정, 현장스케줄 연동, 관리자 스케줄 관리 기능을 유지하고 UI 레이어만 교체하는 방향으로 작업한다.
